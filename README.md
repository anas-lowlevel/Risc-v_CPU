# RISC-V CPU

A RISC-V processor implemented from scratch in SystemVerilog.

## Overview

This project is an educational implementation of a RISC-V CPU, built to develop an understanding of processor architecture at the RTL level.

## Current Features

The following modules have been implemented:

- Program Counter (PC)
- Instruction Memory
- Register File
- Main Control Unit
- ALU Control Unit
- Arithmetic Logic Unit (ALU)
- Immediate Generator
- Data Memory
- Single-Cycle Datapath

## Building and Testing

```bash
make MODULE=single_cycle_datapath
```
